# 동의대학교 라이프복지학과 홈페이지

동의대학교 라이프복지학과를 소개하는 반응형 정적 홈페이지입니다. `index.html`이 저장소 시작 페이지입니다.

## 포함된 내용
- 학과 소개
- 교수 소개 및 공식 프로필 링크
- 교육과정 요약
- 입학 안내 링크
- 학과 활동 갤러리

## GitHub에 올리기
1. GitHub에 로그인하고 오른쪽 위 `+` → `New repository`를 선택합니다.
2. 저장소 이름을 `life-welfare-homepage`처럼 입력하고 `Public`을 선택한 뒤 `Create repository`를 누릅니다.
3. 이 폴더의 파일(`index.html`, `README.md`)을 저장소의 `Add file` → `Upload files`로 업로드합니다. 폴더 자체가 아니라 **폴더 안의 파일**을 선택하세요.
4. `Commit changes` 버튼으로 업로드를 저장합니다.
5. 저장소에서 `Settings` → `Pages`를 엽니다.
6. Source를 `Deploy from a branch`로 설정합니다.
7. Branch에서 `main`, 폴더에서 `/ (root)`를 고르고 `Save`를 누릅니다.
8. Pages 화면에 표시되는 주소를 열어 확인합니다. 주소 형식은 `https://사용자이름.github.io/저장소이름/`입니다.

## 사진 교체 안내
현재 메인·교수·갤러리 사진은 디자인 시안용 외부 예시 이미지입니다. 공개 전에 학과에서 사용을 허가한 사진 파일로 교체하세요. 사진을 저장소에 업로드한 뒤 HTML 이미지 `src`를 예를 들어 `images/professor.jpg`로 지정하면 됩니다. 교수 사진은 학교의 사용 승인을 받은 이미지를 사용하세요.
